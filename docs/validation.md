## 2026-11-10 Token 缓存与自动测试

- JDK 11、Maven 3.6.2 执行 `mvn -o -B -Dfile.encoding=UTF-8 package`：47 项测试通过，无失败、错误或跳过，JAR 打包成功。
- 修复前的回归用例复现了短有效期被忽略、切换账号或密钥仍使用旧 Token、无有效期仍进入发送请求的问题。
- Token 现在按 `expires_in` 提前 60 秒过期，并关联 AppID、AppSecret。有效期不超过 60 秒时不跨发送复用；刷新失败不会继续用过期 Token 发送。
- 新增用例覆盖缓存复用、账号/密钥切换、空 Token、非法有效期、过期刷新失败后恢复、格式异常响应和发送 POST 不重试。测试沿用禁止应用联网的保护，不访问真实接口。
- 新增 `Offline tests` 工作流：推送或 PR 自动执行测试和打包，不读取 Secrets、不校验真实收件人、不运行发送入口。原手动/定时工作流的发送条件保持不变。
- GitHub Actions 的 JDK 11 构建已通过：[运行 42796211403](https://github.com/NiToot/wechat-push-starter/actions/runs/42796211403)，对应提交 `d5ed7f7`。这次运行只执行离线测试和打包，没有调用真实发送入口。
- README 中英文说明和 CONTRIBUTING 已同步；本地文档链接与工作流 YAML 检查通过。

这些测试不证明真实微信账号、模板、关注状态或手机收件结果，未执行实际发送。
